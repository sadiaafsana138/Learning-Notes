# 🐍 Python Master Cheatsheet

A single, runnable Jupyter notebook covering Python fundamentals — from printing and variables through functions, error handling, files, dates, and more. Every cell uses **only the Python standard library**, is self-contained, and has been executed top to bottom with no errors.

## What's inside

`python_master_cheatsheet.ipynb` — 18 runnable code sections:

| # | Topic | # | Topic |
|---|-------|---|-------|
| 1 | Printing & comments | 10 | Comprehensions |
| 2 | Variables & types | 11 | Functions |
| 3 | Operators | 12 | Lambda, map, filter |
| 4 | Strings | 13 | Error handling |
| 5 | Lists | 14 | Files |
| 6 | Tuples & sets | 15 | Modules & imports |
| 7 | Dictionaries | 16 | Dates & times |
| 8 | Conditionals | 17 | Random numbers |
| 9 | Loops | 18 | `any` / `all` |

## How to use

1. Open `python_master_cheatsheet.ipynb` in Jupyter, VS Code, or Google Colab.
2. Run each cell with `Shift + Enter`, top to bottom.
3. Edit the values and re-run to experiment — that's the fastest way to learn.

**No setup or installs needed** beyond Python 3. Every section uses only built-in modules (`math`, `datetime`, `random`, `os`) that ship with Python.
