## CSE 110/111/310 — Programming + OOP

### Q1. What is a computer program?
**English:** A set of instructions that tells a computer how to perform a task.
**বাংলা:** Computer-কে কী কাজ করতে হবে তা নির্দেশ করা instructions-এর set।

### Q2. What is an algorithm?
**English:** A finite sequence of well-defined steps used to solve a problem.
**বাংলা:** Problem solve করার জন্য logically ordered finite steps।

### Q3. What is a flowchart?
**English:** A graphical representation of an algorithm using standard symbols.
**বাংলা:** Algorithm-এর steps symbol/diagram দিয়ে দেখানো হয়।

### Q4. Why is debugging needed?
**English:** To find and remove errors from a program.
**বাংলা:** Program-এর error খুঁজে ঠিক করার জন্য debugging করা হয়।

### Q5. What is a syntax error?
**English:** An error caused by violating the rules of a programming language.
**বাংলা:** Language-এর grammar/rules ভাঙলে syntax error হয়।

### Q6. Runtime error vs logical error?
**English:** Runtime error occurs during execution; logical error produces incorrect results.
**বাংলা:** চালানোর সময় error = runtime; program চলে কিন্তু result ভুল = logical।

### Q7. What is a data type?
**English:** It specifies the kind of value a variable can store and the operations applicable to it.
**বাংলা:** Variable কী ধরনের data রাখবে তা data type নির্ধারণ করে।

### Q8. What is operator precedence?
**English:** The rules that determine which operators are evaluated first.
**বাংলা:** একাধিক operator থাকলে কোনটা আগে হবে তা precedence ঠিক করে।

### Q9. What is a for loop?
**English:** A loop commonly used when initialization, condition, and update are controlled together.
**বাংলা:** Repeated কাজ করার loop; initialization, condition, update থাকে।

### Q10. What is short-circuit evaluation?
**English:** In logical expressions, evaluation stops as soon as the final result is determined.
**বাংলা:** Result নিশ্চিত হয়ে গেলে বাকি expression evaluate করা হয় না।

### Q11. What is a pointer?
**English:** A variable that stores the address of another variable.
**বাংলা:** Pointer অন্য variable-এর memory address রাখে।

### Q12. What does &a mean in C?
**English:** It gives the address of variable a.
**বাংলা:** a-এর memory address দেয়।

### Q13. What does *p mean?
**English:** It dereferences p and accesses the value at the stored address.
**বাংলা:** p যে address point করে, সেই address-এর value access করে।

### Q14. What is an array?
**English:** A collection of elements accessed using an index; basic arrays use contiguous memory.
**বাংলা:** একই ধরনের elements index দিয়ে access করা হয়।

### Q15. What is a function?
**English:** A reusable block of code that performs a specific task.
**বাংলা:** নির্দিষ্ট কাজের reusable code block।

### Q16. What is recursion?
**English:** A technique where a function calls itself to solve smaller instances of the same problem.
**বাংলা:** Function নিজেকেই call করে ছোট subproblem solve করে।

### Q17. Why is a base case necessary?
**English:** It stops recursive calls and prevents infinite recursion.
**বাংলা:** Recursion থামানোর condition হলো base case।

### Q18. Iteration vs recursion?
**English:** Iteration repeats using loops; recursion repeats through function calls.
**বাংলা:** Loop দিয়ে repeat = iteration; function call দিয়ে repeat = recursion।

### Q19. What is call by value?
**English:** A copy of the argument value is passed to the function.
**বাংলা:** Original variable নয়, তার value-এর copy যায়।

### Q20. What is a data structure?
**English:** A way of organizing and storing data for efficient access and modification.
**বাংলা:** Data efficiently organize/store করার পদ্ধতি।

### Q21. What is syntax?
**English:** The formal rules for writing valid statements in a language.
**বাংলা:** Program লেখার grammar/rules।

### Q22. What is semantics?
**English:** The meaning of valid program constructs.
**বাংলা:** Valid statement-এর meaning/behavior।

### Q23. What is structured programming?
**English:** A programming approach based on clear control structures such as sequence, selection, and iteration.
**বাংলা:** Sequence, selection, iteration-এর structured use।

### Q24. What are the four pillars of OOP?
**English:** Encapsulation, inheritance, polymorphism, and abstraction.
**বাংলা:** OOP-এর চার pillar: encapsulation, inheritance, polymorphism, abstraction।

### Q25. What is a class and object?
**English:** A class is a blueprint; an object is an instance of a class.
**বাংলা:** Class হলো blueprint; object হলো তার বাস্তব instance।

### Q26. What is encapsulation?
**English:** Bundling data and methods together and controlling access to the data.
**বাংলা:** Data ও method একসাথে রেখে access control করা।

### Q27. What is inheritance?
**English:** A mechanism by which a class derives properties/behavior from another class.
**বাংলা:** এক class অন্য class-এর properties/behavior পায়।

### Q28. What is polymorphism?
**English:** The ability of one interface/name to represent different forms of behavior.
**বাংলা:** একই interface/name different behavior দিতে পারে।

### Q29. Overloading vs overriding?
**English:** Overloading uses the same method name with different parameters; overriding redefines inherited behavior.
**বাংলা:** Overloading = same name, different parameters; overriding = inherited method-এর নতুন implementation।

### Q30. What is abstraction?
**English:** Showing essential features while hiding implementation details.
**বাংলা:** Important অংশ দেখিয়ে implementation detail hide করা।

### Q31. What is an interface?
**English:** A contract that specifies methods a class must provide; a class can implement multiple interfaces.
**বাংলা:** Class কী behavior provide করবে তার contract।

### Q32. What are JVM, JRE and JDK?
**English:** JVM executes bytecode; JRE provides runtime environment; JDK provides tools for developing Java programs.
**বাংলা:** JVM চালায়, JRE run করার environment, JDK development toolsসহ।

### Q33. What is an exception?
**English:** An abnormal condition that disrupts normal program execution.
**বাংলা:** Program execution-এর abnormal condition।

## CSE 220/221 — Data Structures + Algorithms

### Q1. Linear vs non-linear data structure?
**English:** Linear structures form a sequence; non-linear structures form hierarchical/network relationships.
**বাংলা:** Array/list/stack/queue linear; tree/graph non-linear।

### Q2. What is time complexity?
**English:** It describes how running time grows with input size.
**বাংলা:** Input বাড়লে execution time কীভাবে বাড়ে।

### Q3. What is space complexity?
**English:** It describes memory required as a function of input size.
**বাংলা:** Algorithm-এর required memory।

### Q4. Big-O, Big-Ω, Big-Θ?
**English:** O is an upper bound, Ω a lower bound, and Θ a tight asymptotic bound.
**বাংলা:** Upper, lower এবং tight bound।

### Q5. Why is array access O(1)?
**English:** The address can be calculated directly from the index.
**বাংলা:** Index থেকে direct address পাওয়া যায়।

### Q6. What is a linked list?
**English:** A collection of nodes containing data and links to other nodes.
**বাংলা:** Node-এর data ও link/reference থাকে।

### Q7. What is a stack?
**English:** A LIFO linear data structure.
**বাংলা:** Last In, First Out।

### Q8. Stack operations?
**English:** Push inserts, pop removes the top, and peek views the top.
**বাংলা:** Push ঢোকায়, pop বের করে, peek top দেখায়।

### Q9. What is a queue?
**English:** A FIFO linear data structure.
**বাংলা:** First In, First Out।

### Q10. Types of queue?
**English:** Linear queue, circular queue, priority queue, and deque.
**বাংলা:** চারটি common type।

### Q11. What is recursion?
**English:** A function calls itself on smaller instances with a base case.
**বাংলা:** Self-call + base case।

### Q12. What is a tree?
**English:** A hierarchical non-linear data structure of nodes connected by edges.
**বাংলা:** Hierarchy-based non-linear structure।

### Q13. Binary tree?
**English:** A tree in which each node has at most two children.
**বাংলা:** প্রতি node-এর সর্বোচ্চ দুই child।

### Q14. Tree traversals?
**English:** Preorder: Root-Left-Right; Inorder: Left-Root-Right; Postorder: Left-Right-Root; Level order: level by level.
**বাংলা:** Pre/ In/ Post-এ root-এর position মনে রাখবে; level order level-wise।

### Q15. What is a BST?
**English:** A binary tree where left-subtree keys are smaller and right-subtree keys are larger, subject to duplicate policy.
**বাংলা:** Left ছোট, right বড়।

### Q16. Important BST fact?
**English:** Inorder traversal of a BST produces sorted order.
**বাংলা:** BST-এর inorder = sorted sequence।

### Q17. What is a heap?
**English:** A complete binary tree satisfying a heap-order property.
**বাংলা:** Complete binary tree + heap order।

### Q18. What is hashing?
**English:** Mapping a key to an index using a hash function for fast average-case lookup.
**বাংলা:** Hash function key থেকে table position দেয়।

### Q19. What is collision?
**English:** When multiple keys map to the same hash index.
**বাংলা:** একাধিক key একই index-এ গেলে collision।

### Q20. BFS vs DFS?
**English:** BFS explores level-wise using a queue; DFS explores deeply using a stack/recursion.
**বাংলা:** BFS = queue/level; DFS = stack/recursion/depth।

### Q21. Linear vs binary search?
**English:** Linear search scans sequentially; binary search repeatedly halves a sorted search space.
**বাংলা:** Linear sequential; binary sorted data-তে half করে।

### Q22. Common sorting complexities?
**English:** Bubble/Selection/Insertion are generally O(n²); Merge is O(n log n); Quick is average O(n log n), worst O(n²); Heap is O(n log n).
**বাংলা:** এই complexityগুলো অবশ্যই মনে রাখবে।

### Q23. What is Divide and Conquer?
**English:** Divide the problem, solve subproblems, then combine their results.
**বাংলা:** Divide → solve → combine।

### Q24. What is Greedy method?
**English:** It repeatedly chooses the locally best option according to a greedy rule.
**বাংলা:** প্রতি ধাপে locally best choice নেয়।

### Q25. What is Dynamic Programming?
**English:** It solves overlapping subproblems and stores results to avoid repeated computation.
**বাংলা:** Overlapping subproblem + stored results।

### Q26. Greedy vs DP?
**English:** Greedy commits to local choices; DP evaluates/stores subproblem solutions.
**বাংলা:** Greedy local decision; DP systematic subproblem solution।

### Q27. What is backtracking?
**English:** A search technique that builds a solution and abandons a partial solution when it cannot lead to a valid answer.
**বাংলা:** Invalid path হলে ফিরে গিয়ে অন্য path try করে।

## CSE 260 — Digital Logic Design

### Q1. What is a digital system?
**English:** A system that processes discrete values, commonly binary 0 and 1.
**বাংলা:** Discrete value, সাধারণত 0/1, process করে।

### Q2. What is Boolean algebra?
**English:** A mathematical system for manipulating binary variables using logical operations.
**বাংলা:** 0/1 variable দিয়ে logical expression manipulate/simplify করা হয়।

### Q3. De Morgan's laws?
**English:** (A·B)' = A' + B' and (A+B)' = A'·B'.
**বাংলা:** Complement করলে AND/OR বদলায় এবং variables complement হয়।

### Q4. AND, OR, NOT?
**English:** AND is 1 only when all inputs are 1; OR is 1 when at least one is 1; NOT complements input.
**বাংলা:** AND সব 1; OR যেকোনো 1; NOT উল্টে দেয়।

### Q5. NAND and NOR?
**English:** NAND is NOT-AND and NOR is NOT-OR; both are universal gates.
**বাংলা:** দুটো দিয়েই যেকোনো Boolean circuit বানানো যায়।

### Q6. XOR vs XNOR?
**English:** XOR is 1 for different inputs; XNOR is 1 for equal inputs.
**বাংলা:** XOR different=1; XNOR same=1।

### Q7. Combinational vs sequential circuit?
**English:** Combinational depends only on current inputs; sequential depends on current inputs and stored state.
**বাংলা:** Sequential-এর memory/state থাকে।

### Q8. Half Adder?
**English:** Adds two 1-bit inputs: Sum=A⊕B, Carry=A·B.
**বাংলা:** দুই bit যোগ করে Sum ও Carry।

### Q9. Full Adder?
**English:** Adds A, B and Cin: Sum=A⊕B⊕Cin; Cout=AB+ACin+BCin.
**বাংলা:** Carry-in সহ addition।

### Q10. Decoder?
**English:** Converts n input lines into up to 2ⁿ output lines.
**বাংলা:** n input → সর্বোচ্চ 2ⁿ output।

### Q11. Encoder?
**English:** Converts an active input into a binary code.
**বাংলা:** Input line → binary code।

### Q12. MUX?
**English:** Selects one of multiple inputs and sends it to one output.
**বাংলা:** অনেক input থেকে একটি select করে।

### Q13. DEMUX?
**English:** Routes one input to one of multiple outputs using select lines.
**বাংলা:** এক input থেকে selected output line-এ পাঠায়।

### Q14. What is a flip-flop?
**English:** A bistable storage element used in sequential circuits.
**বাংলা:** 1 bit state store করার memory element।

### Q15. SR, D, JK, T flip-flops?
**English:** SR sets/resets; D stores the input; JK is an SR-like flip-flop without the invalid SR state; T toggles.
**বাংলা:** প্রতিটির basic behavior মনে রাখবে।

### Q16. Synchronous vs asynchronous counter?
**English:** Synchronous counters use a common clock; asynchronous counters ripple the clock through stages.
**বাংলা:** Common clock বনাম ripple clock।

### Q17. Mealy vs Moore?
**English:** Mealy output depends on state and input; Moore output depends only on state.
**বাংলা:** Mealy = state+input; Moore = state।

### Q18. MUX selection rule?
**English:** n select lines can select one of 2ⁿ inputs.
**বাংলা:** n select → 2ⁿ input।

## CSE 370 + SQL — Database

### Q1. What is a DBMS?
**English:** Software that stores, organizes, retrieves, and manages data in databases.
**বাংলা:** Database manage করার software।

### Q2. DBMS vs file system?
**English:** DBMS provides structured database management, querying, integrity and controlled access; a basic file system manages files directly.
**বাংলা:** DBMS বেশি structured control/query/integrity দেয়।

### Q3. What is a relational database?
**English:** A database model that represents data using relations/tables.
**বাংলা:** Table/relation দিয়ে data represent করে।

### Q4. What is a relation, tuple and attribute?
**English:** Relation is a table, tuple is a row, and attribute is a column.
**বাংলা:** Table=row/column terminology: relation, tuple, attribute।

### Q5. Primary key?

### Q6. Foreign key?

### Q7. Candidate key?
**English:** A minimal set of attributes that can uniquely identify a row.

### Q8. What is SQL?
**English:** A language used to define, query, manipulate, and control relational database data.
**বাংলা:** Relational database-এর সাথে কাজ করার language।

### Q9. DDL vs DML?

**বাংলা:** DDL structure; DML data manipulation।

### Q10. SELECT, WHERE, ORDER BY?
**English:** SELECT chooses columns/expressions; WHERE filters rows; ORDER BY sorts results.

### Q11. GROUP BY vs HAVING?
**English:** GROUP BY forms groups; HAVING filters groups after aggregation.
**বাংলা:** GROUP BY group বানায়; HAVING group filter করে।

### Q12. Aggregate functions?
**English:** Functions such as COUNT, SUM, AVG, MIN and MAX summarize data.
**বাংলা:** Multiple row-এর summary দেয়।

### Q13. JOIN?
**English:** A JOIN combines rows from tables based on related columns/conditions.
**বাংলা:** Related table-এর data combine করে।

### Q14. INNER vs LEFT JOIN?
**English:** INNER returns matching rows; LEFT returns all left-table rows plus matches from the right.
**বাংলা:** INNER = matching; LEFT = left-এর সব।

### Q15. DELETE vs TRUNCATE vs DROP?
**English:** DELETE removes rows; TRUNCATE removes table rows quickly; DROP removes the table object.
**বাংলা:** DELETE row, TRUNCATE data, DROP table।

### Q16. Normalization?
**English:** A database design technique that reduces redundancy and update anomalies.
**বাংলা:** Redundancy/anomaly কমানোর জন্য table structure organize করা।

### Q17. 1NF, 2NF, 3NF?
**English:** 1NF requires atomic values; 2NF removes partial dependency; 3NF removes transitive dependency.
**বাংলা:** Atomic → partial dependency remove → transitive dependency remove।

### Q18. ACID?
**English:** Atomicity, Consistency, Isolation, Durability are key transaction properties.
**বাংলা:** Transaction-এর চারটি property।

### Q19. COMMIT vs ROLLBACK?
**English:** COMMIT makes transaction changes permanent; ROLLBACK undoes uncommitted changes.
**বাংলা:** Commit save/permanent; rollback undo।

### Q20. Authentication vs authorization?
**English:** Authentication verifies identity; authorization determines permitted actions.
**বাংলা:** কে তুমি বনাম কী করতে পারবে।

## CSE 320/421 — Networks

### Q1. What is data communication?
**English:** Exchange of data between devices through a medium using communication rules/protocols.
**বাংলা:** Device-to-device data exchange।

### Q2. Analog vs digital signal?
**English:** Analog varies continuously; digital uses discrete levels.
**বাংলা:** Continuous বনাম discrete।

### Q3. Bandwidth vs bit rate?
**English:** Bandwidth is channel frequency range; bit rate is bits transmitted per second.
**বাংলা:** Bandwidth frequency range; bit rate bps।

### Q4. Baud rate?
**English:** Number of signal symbols transmitted per second.
**বাংলা:** প্রতি second-এ symbol সংখ্যা।

### Q5. Noise?
**English:** Unwanted disturbance that can corrupt a signal.
**বাংলা:** Unwanted signal disturbance।

### Q6. Attenuation?
**English:** Loss of signal strength as it travels.
**বাংলা:** Distance-এর সাথে signal দুর্বল হয়।

### Q7. What is modulation?
**English:** Varying a carrier according to an information signal for transmission.
**বাংলা:** Carrier modify করে information পাঠানো।

### Q8. AM vs FM vs PM?
**English:** AM changes amplitude; FM changes frequency; PM changes phase.
**বাংলা:** কোন carrier property change হচ্ছে সেটা মনে রাখবে।

### Q9. ASK/FSK/PSK?
**English:** ASK changes amplitude, FSK frequency, and PSK phase to represent digital symbols.
**বাংলা:** Digital modulation-এর তিনটি basic form।

### Q10. QAM?
**English:** Uses both amplitude and phase to represent multiple bits per symbol.
**বাংলা:** Amplitude + phase ব্যবহার করে।

### Q11. Multiplexing?
**English:** Combining multiple signals so they share a communication link.
**বাংলা:** এক channel-এ multiple signal share।

### Q12. FDM vs TDM vs WDM?
**English:** FDM uses frequency bands; TDM uses time slots; WDM uses optical wavelengths.
**বাংলা:** Frequency বনাম time বনাম wavelength।

### Q13. Error detection?
**English:** Adds redundancy so the receiver can detect corruption.
**বাংলা:** Extra information দিয়ে error detect।

### Q14. Parity vs checksum vs CRC?
**English:** Parity is simple; checksum computes a data-derived value; CRC uses modulo-2 polynomial division and is stronger.
**বাংলা:** CRC তুলনামূলকভাবে powerful error detection।

### Q15. ARQ?
**English:** Automatic Repeat reQuest retransmits damaged/lost frames based on feedback.
**বাংলা:** Error হলে retransmission।

### Q16. TCP vs UDP?
**English:** TCP is connection-oriented and reliable; UDP is connectionless with lower overhead and no delivery guarantee.
**বাংলা:** TCP reliable; UDP lightweight/no guarantee।

### Q17. What is congestion control?
**English:** Techniques that prevent excessive traffic from overwhelming network capacity.
**বাংলা:** Network overload কমায়।

### Q18. What is a protocol?
**English:** A set of rules governing communication between network entities.
**বাংলা:** Communication-এর rules।

### Q19. LAN vs WAN?
**English:** LAN covers a smaller local area; WAN spans larger geographic areas.
**বাংলা:** Local বনাম wide geographic area।

## CSE 470/321 — Software Engineering + OS

### Q1. What is software engineering?
**English:** A systematic approach to developing, operating, and maintaining software.
**বাংলা:** Systematic software development ও maintenance approach।

### Q2. Functional vs non-functional requirement?
**English:** Functional states what the system does; non-functional states qualities/constraints such as performance or security.
**বাংলা:** What system does বনাম quality/constraint।

### Q3. Verification vs validation?
**English:** Verification checks whether the product is built correctly; validation checks whether the right product is built.
**বাংলা:** Build it right বনাম build the right thing।

### Q4. Cohesion vs coupling?
**English:** Cohesion measures how closely related responsibilities within a module are; coupling measures dependency between modules.
**বাংলা:** High cohesion, low coupling desirable।

### Q5. What is software maintenance?
**English:** Modification of software after delivery to correct, adapt, improve, or prevent problems.
**বাংলা:** Delivery-এর পর software modify করা।

### Q6. Types of maintenance?
**English:** Corrective, adaptive, perfective, and preventive.
**বাংলা:** Bug fix, environment adaptation, improvement, future problem prevention।

### Q7. What is SDLC?
**English:** A structured lifecycle for planning, developing, testing, deploying, and maintaining software.
**বাংলা:** Software development-এর lifecycle।

### Q8. Waterfall vs Agile?
**English:** Waterfall is sequential and plan-driven; Agile is iterative and incremental with frequent feedback.
**বাংলা:** Sequential বনাম iterative।

### Q9. What is an operating system?
**English:** System software that manages hardware/resources and provides services to programs.
**বাংলা:** Hardware/resource manage করে এবং application-কে services দেয়।

### Q10. Program vs process?
**English:** A program is passive code; a process is a program in execution.
**বাংলা:** Program = code; process = running program।

### Q11. Concurrent process?
**English:** Processes whose executions overlap in time.
**বাংলা:** Execution time overlap করে।

### Q12. Mutual exclusion?
**English:** Ensures only one process/thread at a time enters a critical section.
**বাংলা:** একসাথে একটিই critical section-এ ঢুকতে পারে।

### Q13. Critical section?
**English:** A code section that accesses shared data/resources and requires controlled access.
**বাংলা:** Shared resource access-এর sensitive code অংশ।

### Q14. Semaphore?
**English:** A synchronization primitive used to control access to shared resources.
**বাংলা:** Process/thread synchronization-এর tool।

### Q15. Deadlock?
**English:** A state where processes wait indefinitely for resources held by one another.
**বাংলা:** একজন আরেকজনের resource-এর জন্য আটকে থাকে।

### Q16. Four deadlock conditions?
**English:** Mutual exclusion, hold and wait, no preemption, and circular wait.
**বাংলা:** এই চারটি condition অবশ্যই মুখস্থ।

### Q17. CPU scheduling?
**English:** Selecting which ready process gets CPU time.
**বাংলা:** Ready queue থেকে next process select করা।

### Q18. FCFS vs SJF vs Round Robin?
**English:** FCFS serves arrival order; SJF chooses shortest job; Round Robin gives processes time slices.
**বাংলা:** Arrival order বনাম shortest job বনাম time quantum।

### Q19. Paging?
**English:** A memory-management scheme that divides logical memory into pages and physical memory into frames.
**বাংলা:** Logical memory = page, physical memory = frame।

### Q20. Logical vs physical address?
**English:** Logical address is generated by the CPU/program; physical address identifies the actual memory location.
**বাংলা:** Program/CPU address বনাম actual memory address।

### Q21. File system?
**English:** The OS component that organizes, stores, names, and accesses files.
**বাংলা:** Files organize/store/access করে।

## ML/DL — High Yield

### Q1. AI vs ML vs DL?
**English:** AI is the broad field; ML learns patterns from data; DL uses multi-layer neural networks.
**বাংলা:** AI broad, ML data থেকে শেখে, DL deep neural network ব্যবহার করে।

### Q2. Supervised vs unsupervised learning?
**English:** Supervised uses labeled data; unsupervised finds patterns in unlabeled data.
**বাংলা:** Labelled বনাম unlabelled data।

### Q3. Classification vs regression?
**English:** Classification predicts categories; regression predicts continuous values.
**বাংলা:** Class/category বনাম numeric continuous value।

### Q4. What is overfitting?
**English:** A model fits training data too closely and performs poorly on unseen data.
**বাংলা:** Training ভালো কিন্তু new data-তে খারাপ।

### Q5. What is underfitting?
**English:** A model is too simple to capture important patterns.
**বাংলা:** Model যথেষ্ট pattern শিখতে পারে না।

### Q6. Bias-variance tradeoff?
**English:** High bias reflects underfitting; high variance reflects sensitivity/overfitting; model selection balances them.
**বাংলা:** Underfit ↔ high bias; overfit ↔ high variance।

### Q7. Training/validation/test set?
**English:** Training fits the model; validation helps tune choices; test estimates final generalization.
**বাংলা:** Train শেখায়, validation tune করে, test final evaluation।

### Q8. What is cross-validation?
**English:** A method that repeatedly trains/validates on different splits to estimate model performance.
**বাংলা:** Different split-এ বারবার train/validate করে।

### Q9. What is linear regression?
**English:** A model that predicts a continuous target using a linear relationship with features.
**বাংলা:** Continuous value-এর জন্য linear model।

### Q10. What is logistic regression?
**English:** A classification model that commonly estimates class probability using a logistic function.
**বাংলা:** Classification-এর probability estimate করে।

### Q11. What is KNN?
**English:** Predicts using the labels/values of nearby training examples.
**বাংলা:** Nearest neighbors দেখে prediction।

### Q12. What is a decision tree?
**English:** A tree of decision rules that recursively splits data to make predictions.
**বাংলা:** Rule-based tree দিয়ে data split করে।

### Q13. Random Forest?
**English:** An ensemble of decision trees whose predictions are combined.
**বাংলা:** অনেক decision tree-এর ensemble।

### Q14. What is SVM?
**English:** A model that seeks a separating hyperplane with maximum margin between classes.
**বাংলা:** Classes-এর মাঝে maximum-margin boundary খোঁজে।

### Q15. What is K-Means?
**English:** An iterative clustering method that assigns points to k clusters around centroids.
**বাংলা:** Data-কে kটি centroid-based cluster-এ ভাগ করে।

### Q16. What is PCA?
**English:** A dimensionality-reduction technique that transforms data into principal components capturing major variance.
**বাংলা:** কম dimension-এ data represent করে major variance ধরে।

### Q17. Confusion matrix?
**English:** A table of TP, TN, FP and FN for classification outcomes.
**বাংলা:** Classification-এর চার outcome-এর table।

### Q18. Precision vs recall?
**English:** Precision = TP/(TP+FP); Recall = TP/(TP+FN).
**বাংলা:** Precision = predicted positive-এর মধ্যে correct; Recall = actual positive-এর মধ্যে found।

### Q19. F1-score?
**English:** F1 is the harmonic mean of precision and recall: 2PR/(P+R).
**বাংলা:** Precision ও recall-এর balanced measure।

### Q20. What is an ANN?
**English:** A neural network of interconnected computational units that learns weighted representations.
**বাংলা:** Connected neurons/units দিয়ে learning model।

### Q21. Activation function?
**English:** A nonlinear function applied to neuron output to enable nonlinear learning.
**বাংলা:** Non-linearity আনে।

### Q22. ReLU?
**English:** ReLU(x)=max(0,x).
**বাংলা:** Negative হলে 0, positive হলে x।

### Q23. Forward propagation?
**English:** Passing input through network layers to compute predictions.
**বাংলা:** Input থেকে layer-by-layer output তৈরি।

### Q24. Backpropagation?
**English:** Computing gradients of the loss with respect to parameters and propagating them backward.
**বাংলা:** Loss-এর gradient backward পাঠিয়ে weights update-এর জন্য ব্যবহার করে।

### Q25. Gradient descent?
**English:** An optimization method that updates parameters in the direction that reduces loss.
**বাংলা:** Loss কমানোর direction-এ parameter update।

### Q26. Learning rate?
**English:** Controls the step size of parameter updates during optimization.
**বাংলা:** প্রতি update কত বড় হবে।

### Q27. Epoch vs batch size?
**English:** An epoch is one full pass through training data; batch size is samples used per parameter update.
**বাংলা:** Epoch = full dataset pass; batch = এক update-এ sample সংখ্যা।

### Q28. CNN?
**English:** A neural architecture using convolutional operations, especially effective for spatial patterns such as images.
**বাংলা:** Image/spatial pattern-এর জন্য convolution ব্যবহার করে।

### Q29. RNN vs LSTM?
**English:** RNN processes sequences recurrently; LSTM adds gates to better preserve long-term dependencies.
**বাংলা:** LSTM long-term dependency better handle করে।

### Q30. Transformer?
**English:** A sequence model architecture based on attention mechanisms rather than recurrence.
**বাংলা:** Attention-based architecture; recurrence-এর ওপর নির্ভর করে না।
